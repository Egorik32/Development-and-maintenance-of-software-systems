# Лабораторная работа 1.10

## Ожидаемый результат

Главная страница доступна по `/lab1-10/`. Адрес `/lab1-10/city` возвращает «Привет CityServlet», `/lab1-10/park` возвращает «Привет ParkServlet». Это шаблоны сервлетов, таблицы на этом этапе не требуются.

## Задание и запуск

Создание шаблонов сервлетов. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Адрес: http://localhost:8080/lab1-10/
Закройте предыдущий сервер через Ctrl+C перед запуском следующей лабораторной. Другой порт: `.\run.ps1 -Port 8082`.
