Лабораторная работа 1.10. Создание шаблонов сервлетов 
Цель лабораторной работы. 
Получить практические навыки создания шаблонов сервлетов.  
Создание сервлетов 
Для дальнейшей работы над проектом создайте в Git ветку разработки 
dev2. Последующие работы в данной лабораторной работе проводите в ветке 
dev2. 
Как и стандартные классы, сервлеты помещаются в проекте Eclipse в 
папку /src. Добав им в проект  пакет controller, в котором создадим класс  
RoleServlet (/src/main/java/controller), испол ьзуя шаблон Servlet, который 
представляет базовую структуру сервлета. Нажмем правой кнопкой мыши на 
папку /controller и в контекстном меню выберем пункт  New -> Other -> Web  
-> Servlet (рис. 1). 
 
Рисунок 1 – Меню создания сервлета 


2 
 
Далее откроется окно создания сервлета (рис. 2). В поле Class name 
укажем для класса сервлета имя - RoleServlet. Также можно указать пакет для 
сервлета в поле Java package – controller. Если не указать название  пакета, то 
будет применяться пакет по умолчанию. Затем нажмем на кнопку Finish. 
 
Рисунок 2 – Окно создания сервлета 
И в проект будет добавлен сервлет с некоторым стандартным 
содержимым. Изменим код сервлета на следующий: 
 
package controller; 
 
import jakarta.servlet.ServletException; 
import jakarta.servlet.annotation.WebServlet; 
import jakarta.servlet.http.HttpServlet; 
import jakarta.servlet.http.HttpServletRequest; 
import jakarta.servlet.http.HttpServletResponse; 
import java.io.IOException; 
import java.io.PrintWriter; 
 


3 
 
/** 
 * Servlet implementation class RoleServlet_ 
 */ 
@WebServlet("/HelloRoleServlet") 
public class RoleServlet_ extends HttpServlet { 
 private static final long serialVersionUID = 1L; 
        
    /** 
     * @see HttpServlet#HttpServlet() 
     */ 
    public RoleServlet_() { 
        super(); 
        // TODO Auto-generated constructor stub 
    } 
 
 /** 
  * @see HttpServlet#doGet(HttpServletRequest request, 
HttpServletResponse response) 
  */ 
 protected void doGet(HttpServletRequest request, 
HttpServletResponse response) throws ServletException, IOException { 
        response.setContentType("text/html"); 
        PrintWriter writer = response.getWriter(); 
        try { 
            writer.println("<h2>Привет RoleServlet</h2>"); 
        } finally { 
            writer.close();   
        } 
 
 } 
 
 /** 
  * @see HttpServlet#doPost(HttpServletRequest request, 
HttpServletResponse response) 
  */ 
 protected void doPost(HttpServletRequest request, 
HttpServletResponse response) throws ServletException, IOException { 
  // TODO Auto-generated method stub 
  doGet(request, response); 
 } 
 
} 
 
Пакеты jakarta.servlet находятся в библиотеке Server Runtime [Apache 
Tomcat v.10.0], которую необходимо подключить к проекту.

Рисунок 3 – Выбор режима настройки конфигурации Build Path

Рисунок 4 – Переход в режим добавления пути к библиотеке
