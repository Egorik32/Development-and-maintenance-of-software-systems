# Лабораторная работа 1.11

## Запуск в браузере

Откройте [Codespaces](../README.md#запуск-в-браузере). Приложение запускается автоматически: порт 8080, путь `/lab1-11/`. Команда `lab 11` пересобирает работу и показывает ссылку, `lab 11 --domain` демонстрирует модели City и Park. Команды PowerShell ниже относятся к Windows.

## Ожидаемый результат

Веб-приложение `/lab1-11/` открывается, сервлеты пока выводят приветствия. Для показа моделей выполнить `./show_domain.ps1`: выводятся City и Park, затем `PASS: Domain constructors, getters, setters, relationship and toString verified.`.

## Задание и запуск

Создание домена данных. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Адрес: http://localhost:8080/lab1-11/
Закройте предыдущий сервер через Ctrl+C перед запуском следующей лабораторной. Другой порт: `.\run.ps1 -Port 8082`.
