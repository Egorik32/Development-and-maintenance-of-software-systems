# Лабораторная работа 1.12

## Запуск в браузере

Откройте [Codespaces](../README.md#запуск-в-браузере). Приложение запускается автоматически: порт 8080, путь `/lab1-12/`. Команда `lab 12` пересобирает работу и показывает ссылку. Команды PowerShell ниже относятся к Windows.

## Ожидаемый результат

На `/lab1-12/city` и `/lab1-12/park` видны таблицы с тремя тестовыми записями. Список выбора парка заполнен моделями. Данные берутся из памяти сервлетов, PostgreSQL не используется. Добавление пока отключено.

## Задание и запуск

Создание представлений веб приложения. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Адрес: http://localhost:8080/lab1-12/
Закройте предыдущий сервер через Ctrl+C перед запуском следующей лабораторной. Другой порт: `.\run.ps1 -Port 8082`.

Кнопка добавления пока отключена: обработка POST появляется в ЛР 1.14.
