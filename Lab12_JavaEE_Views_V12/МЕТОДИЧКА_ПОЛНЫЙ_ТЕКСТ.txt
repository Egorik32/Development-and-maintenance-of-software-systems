Модификация страницы Должности 
При разработке представлений будет использована с тандартная 
библиотека тегов JSP (JavaServer Pages Standard Tag Library,  JSTL), которая 
является расширением её спецификации  и используется для условной 
обработки, создания циклов, интернационализации страницы, разбора XML 
данных. 
JSTL является альтернативой прямой вставки Java кода в jsp-страницы. 
JSTL представляет собой набор тегов в стиле  HTML, позволяющих 
обращаться к объектам Java и выполнять многие из конструкций языка Java. 
Для использования библиотеки тегов JSTL в проектах Jakarta (Dynamic 
Web 5.0) необходимо скачать библиотеки Jakarta Servlet ( jakarta.servlet.jsp.jstl-
api-3.0.0.jar, jakarta.servlet.jsp.jstl-3.0.1.jar) и  поместить их в папку WEB-
INFO/lib. Данные библиотеки определяют серверный API для обработки 
HTTP-запросов и ответов (рис.1).

Подход к разработке страницы person.jsp аналогичный разработки 
страницы role.jsp за некоторыми исключениями. 
1. При создании тестовых данных требуется создать не только массив 
сотрудников persons, но и массив должностей roles, который 
используется в форме для выбора должности из имеющихся в списке 
должностей. 
2. В форме для задания должности используется  combobox – селектор, 
который позволяет в цикле forEach загрузить список должностей, из 
которого будет выбрана должность для нового сотрудника. 
 
<select name="role" class="form-control"> 
  <option>Выберите должность</option> 
  <c:forEach var="role" items="${roles}"> 
    <option value="${role}">
