# Лабораторная работа 1.13

## Ожидаемый результат

На `/lab1-13/city` и `/lab1-13/park` отображаются записи PostgreSQL из `cityparks_lab13`; на чистой базе это три города и три парка с читаемым русским текстом. Добавление отключено до 1.14. Изменение данных в базе отражается после обновления страницы.

## Задание и запуск

Подключение веб приложения к базе данных. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

На этом компьютере база уже подготовлена. Только при первом запуске на другом компьютере выполнить `./setup_db.ps1` после настройки PostgreSQL. Этот скрипт сбрасывает тестовые таблицы, поэтому не запускайте его для обычного старта или исправления текста. Импорт SQL явно использует UTF-8.

Адрес: http://localhost:8080/lab1-13/
Закройте предыдущий сервер через Ctrl+C перед запуском следующей лабораторной. Другой порт: `.\run.ps1 -Port 8082`.

Кнопка добавления пока отключена: обработка POST появляется в ЛР 1.14.
База данных: cityparks_lab13. Подготовка базы сбрасывает только тестовые таблицы этой лабораторной. Не запускайте setup_db.ps1 после добавления данных, которые хотите сохранить.
