# Лабораторная работа 1.14

## Ожидаемый результат

На `/lab1-14/park` можно добавить парк, затем на `/lab1-14/city` связанный с ним город. Строки появляются на страницах и в `cityparks_lab14`, сохраняются после перезапуска. Редактирование и удаление через веб-интерфейс появятся в 1.15.

## Задание и запуск

Создание новых записей в базе данных. Вариант 12.

Условие: `ЗАДАНИЕ.txt`. Полная методичка и оригинальный PDF находятся в этой папке.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

На этом компьютере база уже подготовлена. Только при первом запуске на другом компьютере выполнить `./setup_db.ps1` после настройки PostgreSQL. Этот скрипт сбрасывает тестовые таблицы, поэтому не запускайте его для обычного старта или исправления текста. Импорт SQL явно использует UTF-8.

Адрес: http://localhost:8080/lab1-14/
Закройте предыдущий сервер через Ctrl+C перед запуском следующей лабораторной. Другой порт: `.\run.ps1 -Port 8082`.

База данных: cityparks_lab14. Подготовка базы сбрасывает только тестовые таблицы этой лабораторной. Не запускайте setup_db.ps1 после добавления данных, которые хотите сохранить.
