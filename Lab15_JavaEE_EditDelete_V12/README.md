# Лабораторная работа 1.15

Редактирование и удаление записей в базе данных. Вариант 12.

Условие: `ЗАДАНИЕ.txt`. Полная методичка и оригинальный PDF находятся в этой папке.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Адрес: http://localhost:8080/lab1-15/
Закройте предыдущий сервер через Ctrl+C перед запуском следующей лабораторной. Другой порт: `.\run.ps1 -Port 8082`.

База данных: cityparks_lab15. На этом компьютере она уже подготовлена. `setup_db.ps1` нужен только для первоначальной подготовки или намеренного сброса: он удаляет текущие записи из тестовых таблиц. Не запускайте его для обычного запуска и исправления текста.

## Ожидаемый результат

На страницах «Города» и «Парки» русский текст отображается без искажений. В исходных данных видны «Ростов-на-Дону», «Шахты», «Сочи», «Парк имени Горького», «Парк Революции», «Олимпийский парк» и правильные статусы и типы парков. Добавленный или измененный русский текст сохраняется после обновления страницы. Подтверждение удаления содержит «Удалить запись?».

## Если повреждены данные

Причина прежней ошибки: UTF-8-файл SQL импортировался с клиентской кодировкой Windows. Импорт теперь явно использует `PGCLIENTENCODING=UTF8`, независимо от настроек терминала, и восстанавливает прежнюю переменную окружения после вызова.

Для проверки без изменения базы:

```powershell
.\repair_encoding.ps1 -CheckOnly
```

Для восстановления уже поврежденных строк без очистки таблиц:

```powershell
.\repair_encoding.ps1
```

Перед восстановлением создается резервная копия `verification/before-encoding-repair-*.dump`. Меняются только обратимо поврежденные текстовые значения; идентификаторы, связи, даты и числовые поля сохраняются. Корректный текст не перекодируется. После восстановления повторная проверка должна показать `PENDING: 0 text fields`. Если вместо букв уже сохранены знаки замены, автоматическое восстановление этих значений невозможно.

Кодировки клиента и сервера PostgreSQL: https://www.postgresql.org/docs/17/multibyte.html.
