# Лабораторная работа 1.15

## Запуск в браузере

Откройте [Codespaces](../README.md#запуск-в-браузере). Приложение запускается автоматически: порт 8080, путь `/lab1-15/`. Команда `lab 15` пересобирает работу и показывает ссылку. База `cityparks_lab15` подготавливается автоматически без сброса существующих записей. Команды PowerShell ниже относятся к Windows.

Редактирование и удаление записей в базе данных. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Адрес: http://localhost:8080/lab1-15/
Закройте предыдущий сервер через Ctrl+C перед запуском следующей лабораторной. Другой порт: `.\run.ps1 -Port 8082`.

База данных: cityparks_lab15. На этом компьютере она уже подготовлена. `setup_db.ps1` нужен только для первоначальной подготовки или намеренного сброса: он удаляет текущие записи из тестовых таблиц. Не запускайте его для обычного запуска и исправления текста.

## Ожидаемый результат

На страницах «Города» и «Парки» русский текст отображается без искажений. В исходных данных видны «Ростов-на-Дону», «Шахты», «Сочи», «Парк имени Горького», «Парк Революции», «Олимпийский парк» и правильные статусы и типы парков. Добавленный или измененный русский текст сохраняется после обновления страницы. Подтверждение удаления содержит «Удалить запись?».

Импорт SQL и страницы приложения используют UTF-8.
