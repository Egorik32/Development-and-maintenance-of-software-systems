# ЛР 1.1 Анонимные классы

## Ожидаемый результат

В консоли выводятся три города с населением и характеристиками парков. Ростов-на-Дону отмечен как крупный город; у Шахт указан парк без водоёма. Учебный пример отдельно выводит `Hello world`, `Salut Fred`, `Hola, mundo`.

## Задание и запуск

Вариант 12: города и парки.

## Запуск варианта 12

```powershell
.\run.ps1
```

## Учебный пример из методички

```powershell
.\run_examples.ps1
```

Исходники находятся в `examples/01_HelloWorld`: интерфейс `HelloWorld`, класс `EnglishGreeting` и `HelloWorldAnonymous` с двумя анонимными реализациями.

Ожидаемый вывод: `Hello world`, `Salut Fred`, `Hola, mundo`. Скрипт компилирует пример отдельно от варианта 12 и проверяет вывод в терминале.
