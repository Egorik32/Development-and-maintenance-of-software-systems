# ЛР 1.2 Лямбда выражения

## Ожидаемый результат

Фильтр городов с водоёмом выводит Ростов-на-Дону и Сочи; крупные города: Ростов-на-Дону. Среднее население: `611564.0`. Самый старый парк: Парк Революции. Для учебных примеров ожидается `RESULT: ALL 13 SELECTED EXAMPLES PASSED`.

## Задание и запуск

Вариант 12: города и парки.

## Запуск варианта 12

```powershell
.\run.ps1
```

## Учебные примеры из методички

Все примеры:

```powershell
.\run_examples.ps1
```

Отдельный пример, например ссылка на конструктор:

```powershell
.\run_examples.ps1 -Number 12
```

| Номер | Пример | Ожидаемый вывод |
| --- | --- | --- |
| 1 | Сложение через лямбду | 30 |
| 2 | Эквивалентный анонимный класс | 30 |
| 3 | Сложение, вычитание, умножение | 30, 10, 200 |
| 4 | Терминальная лямбда | Hello Java! |
| 5 | Переменные класса | 50, 30 |
| 6 | Локальные переменные | 100 |
| 7 | Блочная лямбда с проверкой деления | 2, 0 |
| 8 | Обобщенный функциональный интерфейс | 30, 2010 |
| 9 | Лямбда как параметр метода | 20, 30 |
| 10 | Ссылки на статические методы | 20, 45 |
| 11 | Ссылка на метод объекта | 0 |
| 12 | Ссылка на конструктор | Tom |
| 13 | Лямбда как результат метода | 11, 6 |

Каждый пример находится в своей папке `examples`, поэтому одинаковые имена `LambdaApp` и интерфейсов не конфликтуют. Скрипт компилирует каждую папку отдельно, сверяет весь вывод с `examples/examples.json` и показывает результат в терминале.
