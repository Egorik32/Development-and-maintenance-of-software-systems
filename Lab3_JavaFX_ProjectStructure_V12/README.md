# Лабораторная работа 1.3

## Ожидаемый результат

Открывается окно JavaFX с пустой таблицей и каркасом карточки. Ошибок загрузки FXML нет. Пустая таблица на этом этапе ожидаема; данные появятся в 1.4, обработчики кнопок в 1.5.

## Задание и запуск

Создание структуры проекта и проектирование пользовательского интерфейса. Вариант 12.

Условие: `ЗАДАНИЕ.txt`. Учебник: https://code.makery.ch/ru/library/javafx-tutorial/part1/

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Java 8 с JavaFX берется из соседней папки `runtime`, системный путь к Java не используется.

На этом этапе кнопки изменения данных еще не реализуются: они добавляются в ЛР 1.5.
