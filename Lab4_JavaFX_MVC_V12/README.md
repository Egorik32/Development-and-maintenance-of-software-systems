# Лабораторная работа 1.4

## Ожидаемый результат

Открывается JavaFX-окно с тремя городами: Ростов-на-Дону, Шахты и Сочи. Колонки показывают название и статус из ObservableList. Подробная карточка и редактирование ещё не реализуются: это следующий этап.

## Задание и запуск

Создание компонентов MVC. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Java 8 с JavaFX берется из соседней папки `runtime`, системный путь к Java не используется.

На этом этапе кнопки изменения данных еще не реализуются: они добавляются в ЛР 1.5.
