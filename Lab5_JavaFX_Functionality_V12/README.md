# Лабораторная работа 1.5

## Ожидаемый результат

Выбор города заполняет карточку. «Добавить», «Изменить» и «Удалить» меняют таблицу; «Отмена» не сохраняет изменение. Пустые строки, неположительное население и некорректная площадь вызывают ошибку ввода и не попадают в список. После перезапуска используются исходные данные: XML добавляется в 1.7.

## Задание и запуск

Разработка функционала приложения. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Java 8 с JavaFX берется из соседней папки `runtime`, системный путь к Java не используется.
