# Лабораторная работа 1.6

## Ожидаемый результат

Открывается оформленное CSS окно с иконкой парка, тремя городами и действующими кнопками. Окно редактирования имеет ту же таблицу стилей и иконку. Оформление здесь светлое; переключатель тёмной темы добавлен только в 1.8.

## Задание и запуск

Стилизация представлений с помощью CSS. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Java 8 с JavaFX берется из соседней папки `runtime`, системный путь к Java не используется.
