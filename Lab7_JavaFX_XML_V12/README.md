# Лабораторная работа 1.7

## Ожидаемый результат

В меню «Файл» доступны создание, открытие и сохранение XML через FileChooser. Сохранённый файл восстанавливает города и все поля парков. После перезапуска загружается последний существующий XML, поэтому пользовательские записи могут отличаться от трёх исходных.

## Задание и запуск

Работа с данными в XML. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Java 8 с JavaFX берется из соседней папки `runtime`, системный путь к Java не используется.
