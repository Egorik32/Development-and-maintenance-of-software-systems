# Лабораторная работа 1.8

Развертывание приложения. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Java 8 с JavaFX берется из соседней папки `runtime`, системный путь к Java не используется.

## Тёмная тема

В главном окне откройте **Вид → Тёмная тема**. Галочка включает тёмное оформление; повторное нажатие возвращает светлое. Выбор сохраняется в Preferences и восстанавливается после закрытия и повторного запуска приложения. Тема применяется к таблице, карточке, окну редактирования и сообщениям об ошибках. Данные при переключении не меняются.

После обновления исходников запускайте `run.ps1`, чтобы пересобрать EXE и обновить копию в `%LOCALAPPDATA%\CityParksLab8`. Уже открытое старое окно нужно закрыть. Вся папка нативного пакета нужна целиком: `CityParks.exe`, `app` и `runtime`.

Во время работы окна терминал ожидает его закрытия. После обычного закрытия появляется `Native application closed normally.`.

## Ожидаемый результат

Сначала в терминале заканчивается сборка сообщением `BUILD SUCCESSFUL`. Открывается окно «Города и парки» с тремя исходными городами или данными последнего сохранённого XML. В меню доступны «Файл» и «Вид». Работают добавление, изменение, удаление и сохранение XML; после выбора тёмной темы главное окно и диалог редактирования имеют тёмный фон и светлый текст.

Если есть сохранённые пользовательские изменения, названия и количество строк могут отличаться от исходных трёх записей. Это нормальная загрузка последнего XML, а не ошибка.
