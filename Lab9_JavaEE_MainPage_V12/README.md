# Лабораторная работа 1.9

## Запуск в браузере

Откройте [Codespaces](../README.md#запуск-в-браузере). Приложение запускается автоматически: порт 8080, путь `/lab1-9/`. Команда `lab 9` пересобирает работу и показывает ссылку. Команды PowerShell ниже относятся к Windows.

## Ожидаемый результат

После запуска Tomcat открывается `/lab1-9/`: видны «Города и парки», главное меню, общий header и footer. Наведение на «Поднеси ко мне курсор» показывает «Ура, Bootstrap 5 работает». Страницы данных этого этапа ещё не реализованы.

## Задание и запуск

Создание главной страницы проекта Java EE. Вариант 12.

Откройте эту папку в VS Code, затем терминал PowerShell:

```powershell
.\run.ps1
```

Адрес: http://localhost:8080/lab1-9/
Закройте предыдущий сервер через Ctrl+C перед запуском следующей лабораторной. Другой порт: `.\run.ps1 -Port 8082`.

Главная страница и меню. Ссылки на данные подключаются в ЛР 1.10.

По методичке локально подключены jQuery 3.6.4 и Bootstrap 5 с Popper. Наведите курсор на кнопку «Поднеси ко мне курсор»: появляется сообщение «Ура, Bootstrap 5 работает». После ухода курсора оно скрывается. Код подключения находится в `index.jsp`, инициализация через jQuery находится в `js/bootstrap-check.js`.

Библиотеки лежат в `src/main/webapp/js`; для загрузки страницы интернет не нужен.
