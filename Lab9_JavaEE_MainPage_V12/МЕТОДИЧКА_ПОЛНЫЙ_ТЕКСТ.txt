Лабораторная работа 1.9. Создание главной страницы проекта Java EE 
Цель лабораторной работы. 
Получить практические навыки создания проекта по шаблону Dynamic 
Web Project и главной страницы проекта.  
Введение 
Данной работой начинается цикл лабораторных работ по созданию веб-
приложения на базе технологии Java Enterprise Editional. Приложение 
ориентировано на обработку данных о сотрудниках предприятия и будет 
взаимодействовать с базой данных PostgresSQL. Модель данных содержит две 
сущности Сотрудники и Должности. Приложение должно обеспечивать вывод 
данных по сотрудникам и должностям, добавление новых , редактирование и 
удаление данных о сотрудниках и должностях. 
Для отслеживания изменений в проекте необходимо применить систему 
контроля версий Git. В главной ветке проекта ( master) должна храниться 
работоспособная версия проекта. Разработка новой функциональности, 
которая определяется заданием на конкретную лабораторную работу, должна 
проводиться в ветке devN, где N – номер лабораторной работы. После 
выполнения текущей лабораторной работы и проверки её преподавателем, 
ветка разработки devN должна быть слита с главной веткой – master. В 
качестве удаленного репозитория рекомендуется использовать GitHub или 
Bitbucket. 
Создание проекта 
Создадим в Eclipse проект по типу Dynamic Web Project с именем persons 
(рис. 1 ). Обратите внимание, что версию Dynamic web model необходимо 
использовать 5-ю, а сервер Apache Tomcat v10.0.

Рисунок 9 - Шаблон представления главной страницы приложения 
Для дизайна страниц веб -проекта будем использовать  фремворк 
Bootstrap и библиотеку jQuery. 
Bootstrap — это открытый и бесплатный HTML, CSS и JS фреймворк, 
который используется веб -разработчиками для быстрой вёрстки адаптивных 
дизайнов сайтов и веб-приложений. 


7 
 
jQuery – набор функций JavaScript, фокусирующийся на взаимодействии 
JavaScript и HTML. Библиотека jQuery помогает легко по лучать доступ к 
любому элементу DOM, обращаться к атрибутам и содержимому элементов 
DOM, манипулировать ими.  
Для стадии разработки веб -приложения будем использо вать локальное 
подключения Bootstrap 5 и jQuery. Для этого необходимо скачать Bootstrap 5 
(https://getbootstrap.com/docs/5.0/getting-started/download/) и jQuery 
(https://jquery.com/download/ ). 
Из архива Bootstrap 5 будем использовать файлы bootstrap.min.css и 
bootstrap.bundle.min.js. Для библиотеки jQuery используем файл jquery-3.6.4.js. 
Файл bootstrap.min.css поместим в папку /persons/src/main/webapp/css/, а 
файлы с расширением .js – в папку /persons/src/main/webapp/js/ (рис. 10).

Внимание.  
1. Стили и настройки Bootstrap необходимо изучить по 
документации (https://bootstrap-4.ru/docs/5.1/getting-
started/introduction/). 
2. Дизайн, как главной страницы, так и других страниц веб -
приложения может быть предложен студентом при согласовании 
с преподавателем. 
 
Изменения в коде проекта необходимо зафиксировать в ветке dev1. 
После проверки работоспособности приложения, демонстрации работы 
приложения преподавателю и одобрения преподавателем текущей 
функциональности ветка dev1 должна быть слита с главной веткой master. 
Состояние локального репозитория необходимо передать в удаленный 
репозиторий.
