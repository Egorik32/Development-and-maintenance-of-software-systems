# Среда запуска лабораторных

Сценарии сборки рассчитаны на Windows x64 и такую структуру папки `runtime`:

```text
runtime/
  java_env.ps1
  java17_env.ps1
  zulu8.96.0.205-ca-fx-jdk8.0.504-win_x64/
  zulu17.66.19-ca-jdk17.0.19-win_x64/
  apache-tomcat-10.0.27/
  ant/lib/
  efx-generator/lib/
```

На исходном компьютере эти каталоги уже есть. В репозитории оставлены сценарии выбора Java, библиотеки Ant и генератора e(fx)clipse; сами JDK и Tomcat не включены из-за размера.

Для повторения проверенного окружения нужны **Zulu JDK 8 с JavaFX** (не обычный JDK 8), Zulu JDK 17 и Tomcat 10.0.27. Распакуйте их в соответствующие каталоги выше. Если используется другая папка совместимого JDK, измените `$jdk` в `java_env.ps1` или `java17_env.ps1`. Имя каталога Tomcat прописано в `run.ps1` каждой веб-работы. JavaFX 8 и JAXB уже входят в проверенный JDK 8 FX; отдельная загрузка современных модулей JavaFX для этих работ не нужна.

Исходники библиотек и дистрибутивы следует брать у поставщиков: Azul Zulu, Apache Tomcat, Apache Ant и Eclipse e(fx)clipse. Старые версии используются для воспроизведения учебного окружения; не разворачивайте этот учебный сервер в интернете.

PostgreSQL устанавливается отдельно. Проверено с версией 17. Сценарии подготовки базы ищут `psql.exe` в стандартных каталогах PostgreSQL 15-18 или в PATH. Настройки учебного подключения находятся в `config.properties` каждой работы 1.13-1.15.

Scene Builder требуется для демонстрации проектирования FXML, но не для обычной сборки и запуска. Скрипт `open_scenebuilder.ps1` ожидает переносимую копию в `runtime/scenebuilder/SceneBuilder`. При другой установке откройте FXML непосредственно из редактора.

Автотесты браузера используют Node.js с Playwright и установленным Chromium/Edge. Node.js должен быть доступен в PATH; другой путь можно передать параметром `-NodePath` в `tools/verify_ee.ps1`. Для подготовки браузерных тестов выполнить `npm install --prefix tools --no-save playwright` и `npx --prefix tools playwright install chromium`. Обычный запуск лабораторных не требует Node.js. Отчёты Word открываются обычным редактором.
