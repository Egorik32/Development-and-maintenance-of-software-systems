# Как запустить лабораторные на показе

Вариант 12: города и парки. Для каждой лабораторной теперь есть отдельная папка. Используй папки `Lab1_...` - `Lab15_...`.

## Запуск из VS Code

Открой в VS Code папку `Moodle_ЛР_часть_1` и терминал PowerShell. Запусти:

```powershell
.\ЗАПУСТИТЬ_ЛАБУ.ps1
```

Появится список. Введи номер, например `3` или `1.3`. Можно запускать сразу выбранную лабораторную:

```powershell
.\ЗАПУСТИТЬ_ЛАБУ.ps1 -Number 3
```

Чтобы команда работала из любой папки, используй полный путь:

```powershell
$LABS = "C:\Users\egor2\OneDrive\Рабочий стол\Домашка\Разработка и сопровождение программных систем\Moodle_ЛР_часть_1"
& "$LABS\ЗАПУСТИТЬ_ЛАБУ.ps1" -Number 3
```

Общий скрипт возвращает терминал в исходную папку после завершения лабораторной. Java берется из `runtime`: Java 8 с JavaFX для 1.1-1.8 и Java 17 для веб-части. Старый системный путь к Java не нужен.

Если PowerShell запрещает запуск скриптов, разреши их только на время текущего терминала:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

## Учебные примеры 1.1 и 1.2

Общий запуск по номеру показывает приложение по варианту 12. Примеры из методичек запускаются отдельно:

```powershell
& "$LABS\Lab1_AnonymousClasses_V12\run_examples.ps1"
& "$LABS\Lab2_LambdaExpressions_V12\run_examples.ps1"
```

В 1.1 выводятся приветствия `Hello world`, `Salut Fred`, `Hola, mundo`. В 1.2 последовательно запускаются 13 примеров. Один пример можно выбрать номером, например ссылка на конструктор:

```powershell
& "$LABS\Lab2_LambdaExpressions_V12\run_examples.ps1" -Number 12
```

Ожидаемый вывод этого примера: `Tom`. Исходники лежат в `examples` нужной лабораторной; номера и результаты перечислены в ее `README.md`. Компиляция выполняется отдельно для каждой папки, поэтому одинаковые имена классов не мешают запуску.

## JavaFX и Scene Builder

Для 1.3-1.7 запуск откроет отдельное окно. После показа закрой его. В 1.7 проверь меню «Файл»: сохрани XML, измени данные, открой сохраненный файл. При перезапуске автоматически загрузится последний открытый файл.

Чтобы показать FXML в настоящем переносимом Scene Builder:

```powershell
& "$LABS\Lab3_JavaFX_ProjectStructure_V12\open_scenebuilder.ps1"
```

В 1.8 `run.ps1` генерирует сборку через официальный генератор плагина e(fx)clipse и запускает нативный пакет. Для старого лаунчера JavaFX 8 требуется путь без кириллицы. Скрипт автоматически размещает готовый пакет в `%LOCALAPPDATA%\CityParksLab8`. Сам пакет содержит `CityParks.exe`, папки `app` и `runtime`.

Для показа развертывания открой `build.fxbuild`, `native-build\build.generated.xml`, `native-build\build.xml` и папку `native-build\deploy\bundles\CityParks`. В этом результате подготовлен самостоятельный пакет, а не отдельный установщик.

Для запуска исходников 1.8 без упаковки используй `run_source.ps1` внутри ее папки.

В 1.8 переключатель оформления находится в меню **«Вид» → «Тёмная тема»**. Галочка включает тёмный режим, снятие галочки возвращает светлый. Настройка сохраняется после перезапуска и применяется к диалогу редактирования. После обновления кода закрывай старое окно и запускай `run.ps1`, чтобы обновилась и нативная копия приложения.

## Веб-работы и база

Каждая веб-работа запускает Tomcat со своей конфигурацией. После запуска открой адрес, напечатанный в терминале, обычно:

```text
http://localhost:8080/lab1-9/
http://localhost:8080/lab1-10/
...
http://localhost:8080/lab1-15/
```

Перед следующей веб-работой останови текущую через `Ctrl+C`. Если порт занят, укажи другой:

Если сервер был запущен в фоне, останови его командой `stop.ps1` внутри папки этой лабораторной. Перед повторным запуском той же папки также останови ее старый сервер.

```powershell
& "$LABS\ЗАПУСТИТЬ_ЛАБУ.ps1" -Number 15 -Port 8082
```

Тогда адрес будет `http://localhost:8082/lab1-15/`. Если браузер использует прокси, для локального сервера попробуй `127.0.0.1` вместо `localhost`.

На этом компьютере базы `cityparks_lab13`, `cityparks_lab14`, `cityparks_lab15` уже подготовлены. У каждой работы своя база; старая `cityparks` не использовалась при новых проверках.

В 1.9 локально подключены jQuery и Bootstrap с Popper. Для проверки из методички наведи курсор на кнопку «Поднеси ко мне курсор» на главной странице: появится «Ура, Bootstrap 5 работает». Файлы библиотек лежат внутри проекта, интернет для их загрузки не требуется.

Для подготовки базы заново запусти `setup_db.ps1` из нужной папки. Это сбросит ее тестовые таблицы и вернет три исходных города и парка. Не запускай подготовку после ввода записей, которые хочешь сохранить.

ЛР 1.11 добавляет домен и не добавляет таблицы в браузере. Для демонстрации ее моделей:

```powershell
& "$LABS\Lab11_JavaEE_Domain_V12\show_domain.ps1"
```

В 1.15 парк, на который ссылается город, защищен внешним ключом. Для демонстрации удаления сначала удали связанный город, затем парк. Удобно добавить отдельные тестовые записи для показа.

## Файлы для защиты

В каждой новой папке: `ЗАДАНИЕ.txt`, `ВАРИАНТ.txt`, исходники, `run.ps1`, `README.md`, отдельный отчет Word и результаты в `verification`. В 1.9-1.15 также лежат оригинальный PDF и полный текст методички.

В веб-папках есть локальная история Git: `master` и соответствующие ветки `dev1`-`dev7`. Удаленный репозиторий, демонстрация преподавателю и загрузка отчетов в Moodle требуют твоего участия; они не выполнялись автоматически.

Папки `CityParksJavaFX`, `CityParksJavaEE` и прежние объединенные отчеты сохранены как предыдущие версии. Для новых отдельных работ используй папки из таблицы выше.
